PhyloTrace is a platform for bacterial pathogen monitoring on a genomic level, built around Core-Genome Multilocus Sequence Typing (cgMLST) and Antimicrobial Resistance Screening. *For research and academic use only.*

**This branch (`v2_conda`) is a work in progress.** It consolidates PhyloTrace's install into a single Conda environment (`environment.yml`) covering R, every R package the app needs, and the external CLI bioinformatics toolchain (pyMLST, blat, mafft, abritamr, amrfinderplus) — no `renv`. Install steps, scripts and docs here are still in flux.

For the full project description, features, and stable installation instructions, see [www.phylotrace.com](https://www.phylotrace.com) or the `master`/`v2` branches.
